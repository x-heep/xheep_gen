# X-HEEP Generator

This repository contains the Python-based generator for [X-HEEP](https://github.com/x-heep/x-heep) and [X-ALP](https://github.com/x-heep/x-alp), our configurable RISC-V SoCs. It produces the RTL, memory map, linker scripts, and other generated files that make up the systems based on a configuration.

## Documentation

See the X-HEEP documentation for details on how the generator is used and how to configure the SoC in the [X-HEEP configuration documentation](https://x-heep.readthedocs.io/en/latest/Configuration/index.html).
